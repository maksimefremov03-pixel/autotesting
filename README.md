### Задание 7

Применённые принципы ООП:

Инкапсуляция: Класс Robot использует private поля (name, movement), а также protected поле (fuelSystem), которое доступно только наследникам. Доступ к данным осуществляется через public методы-геттеры (getName(), getMovement(), getFuel(), getFuelLevel(), needsRefuel()). То есть детали реализации роботов скрыты от внешнего мира, что повышает защищённость, гибкость и упрощает интерфейс.

Наследование: Дочерние классы ролей роботов (Medic, Welder, Cook, MedicWelder, WelderCook, Almighty) наследуются от базового класса Robot через extends. Тем самым они получают доступ к полям и методам родителя, могут переопределять абстрактные методы (move(), doWork()), а также используют конструктор родителя через super().

Полиморфизм: Один и тот же метод в классе каждого робота работает по-разному: например, один робот ходит, а другой летает. Благодаря полиморфизму можно единообразно работать с массивом Robot\[], вызывая одни и те же методы, не зная конкретный тип робота.

Абстракция: Выделяются только существенные характеристики робота (name, movement, fuelSystem), что упрощает код. В абстрактном классе Robot объявлены абстрактные функции (move(), doWork()), которые обозначают действие, но не поясняют их реализацию.

Композиция: Класс Robot содержит ссылку на FuelSystems. Это позволяет гибко подставлять различные типы топливных систем без изменения кода самого робота.



Производим тесты:

testMedic(): тестируем медика;

testWelder(): тестируем сварщика;

testCook(): тестируем повара;

testMedicWelder(): тестируем медика-сварщика;

testWelderCook(): тестируем сварщика-повара;

testAlmighty(): тестируем всемогущего;

testPolymorphism(): тестируем полиморфизм;

testFuelLevelDecreases(): тестируем уменьшение уровня топлива;

testLowFuelLevel(): тестируем низкий уровень топлива;

testCorrectFuelTypes(): проверяем корректность соответствия робота и типа топлива;

testAtomicRefuel(): тестируем заправку атомным топливом;

testInternalCombustionRefuel(): тестируем заправку топливом внутреннего сгорания;

testElectricRefuel(): тестируем заправку электричеством;

testHybridRefuel(): тестируем заправку гибридным топливом.
